# [?] How to Watch:

Using VLC Media Player
1. Open VLC Media Player.
2. Go to Media > Open Network Stream (or press Ctrl + N on Windows / Cmd + N on Mac).
3. Paste the Raw Playlist URL above and click Play.
4. Press Ctrl + L (or Cmd + L) to open the playlist panel and browse categories.
