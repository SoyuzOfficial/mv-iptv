# [?] How to Watch:

### Using VLC Media Player
1. Open VLC Media Player.
2. Go to Media > Open Network Stream (or press Ctrl + N on Windows / Cmd + N on Mac).
3. Paste the Raw Playlist URL above and click Play.
4. Press Ctrl + L (or Cmd + L) to open the playlist panel and browse categories.

### Mobile & Smart TV (IPTV Apps)
1. You can load this playlist into any M3U-compatible IPTV player on Android, iOS, Firestick, or Google TV:

### Recommended IPTV Apps:
1. [TiviMate](https://tivimate.com/) or OTT Navigator. For Android(TV/Mobile)/Firestick
2. UHF, IPTVX, or Smarters Player Lite. For IOS/IPAD Os and TV Os
3. Televizo or IPTV Smarters Pro. For Android(Mobile)


### General Steps (For IPTV Apps)
1. Open your preferred IPTV app and select **Add Playlist** (or **Load M3U URL**).
2. Choose the **M3U URL** / **Remote Playlist** option.
3. Give it a name (e.g., `Maldives TV`).
4. Paste the **Raw Playlist URL** from above and save/update.

**Note:** Streams like PSM and Odysee require custom User-Agent and Referrer headers (`#EXTVLCOPT`). **VLC**, **TiviMate**, and **OTT Navigator** read these automatically. If a specific channel fails to load in a simpler mobile app, try opening it in VLC instead.
